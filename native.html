Um AI nativo, com outro nome. Sem converter nem rasterizar.

A operação é local. Nenhum ficheiro é enviado.

O Illustrator não regista oficialmente a extensão .kutuzov. Se não abrir directamente, converte o nome para .ai aqui, sem alterar o conteúdo. A detecção é estrutural, não uma certificação do Adobe Illustrator.

Script de abertura para Illustrator

Para criar um AI a partir de um design do Studio, descarrega o script de exportação no editor e executa em Ficheiro → Scripts → Outro script. É necessário ter Illustrator instalado.
