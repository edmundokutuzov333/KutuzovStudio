KUTUZOV STUDIO.

Print production.

O PDF directo do Studio tem caixas físicas de corte e sangria, imagens RGB de alta resolução e duas faces. A impressão nativa conserva elementos vectoriais, mas as caixas e dimensões dependem do navegador.

PDF vectorial com caixas exactas

  1. Descarrega e extrai o ZIP de produção do Studio.
  2. Instala Inkscape, Poppler, Python 3 e o módulo pypdf (python3 -m pip install pypdf==5.9.0 num ambiente virtual).
  3. Descarrega o conversor vectorial local para a pasta extraída.
  4. Executa python3 vector_pdf.py front.svg back.svg PRINT-SPEC.json vector.pdf.
  5. Verifica a composição e as fontes locais antes de enviar para impressão. Podes usar vector.pdf como entrada do conversor CMYK abaixo.

Conversão CMYK / PDF/X-3 local

  1. Solicita à gráfica o perfil ICC CMYK e a condição de impressão.
  2. Descarrega o PDF directo do Studio e o conversor local.
  3. Instala Python 3, Ghostscript, Poppler e pypdf (o mesmo ambiente virtual da conversão vectorial).
  4. Executa no terminal: python3 pdfx.py print.pdf perfil.icc print-cmyk.pdf --condition "Condicao da grafica".
  5. Entrega o candidato PDF/X-3 à gráfica para preflight independente e prova de cor.

Não é uma conversão no navegador. Não envia ficheiros a terceiros. O perfil utilizado deve corresponder à gráfica e ao papel. Não garantimos conformidade ISO apenas pelo identificador PDF/X. O diálogo de impressão nativo pode arredondar as caixas; o conversor vectorial local usa a geometria exacta do manifesto.
