# Optional Magnific metadata search
The deployed studio-stock-search function accepts only authenticated current editors at AAL2 and has a global 20-request UTC-day cap. It never calls downloads or generation endpoints; it strips previews, download URLs and license URLs. Unknown prices are null, never zero. Public Studio remains local-only.
Default is disabled. Before activation, obtain written Magnific authorization for this product and verify search is included at zero marginal cost. Then set MAGNIFIC_API_KEY and MAGNIFIC_CURATION_ENABLED=true as Supabase Edge secrets, and STUDIO_ADMIN_ORIGINS to the exact HTTPS origin of the separate Studio (comma-separated). Never expose the key in the repo/client. No secret has been provisioned in this release. Use the private manual candidate workflow otherwise. No automatic public delivery of licensed stock is implemented or authorized.
Docs: https://docs.magnific.com/api-reference/resources/get-all-resources and https://docs.magnific.com/pricing and https://www.magnific.com/legal/terms-of-use.
