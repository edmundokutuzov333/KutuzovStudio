# Author template import engine

Editorial workflow (local isolated machine; no customer uploads to a server). Install Inkscape, Ghostscript, Python 3.11/3.12 and the pinned requirements in an isolated venv. The PyMuPDF dependency is AGPL/commercial-licensed; review its licence for redistribution or hosted operation. It is not bundled into the public browser build. psd-tools is MIT. Never process unknown EPS/AI/PSD in a privileged environment or with network access; keep tools patched.

1. python tools/template_import.py inspect source.zip > report.json
2. Choose front/back source filenames and page indices. Inspect returns text/layer IDs, bounding boxes normalized to the artwork canvas, source fonts and suggested field names. Only exact {{name}} etc or recognized layer names auto-map; otherwise map explicitly.
3. Create spec.json with id,title,product,width,height,bleed,safe,dpi,rights:"editable", sides:{front:{file,page,map},back:{file,page,map}}. Dimensions in mm exclude bleed. Source artwork must include bleed and match aspect. Example map: {"name":{"field":"name","box":[7,9,60,12],"size":5,"color":"#ffffff","font":"sans-serif","weight":700,"align":"start","required":true}}. Box x,y,w,h in trim-relative mm. Omit map to select exact markers. For confirmed already-clean artwork, cleanArtworkConfirmed:true and cleanSlots array can add text/photo/logo/qr/barcode areas. No erasing rasterized or outlined placeholders by covering them.
4. python tools/template_import.py compile source.zip spec.json draft.kutuzov-template
5. Open /templates.html, load draft locally, test real short and long names, both faces, proof print, typography, rights and effective DPI. Existing fixed artwork is rendered into PNG; variable fields are separate SVG elements. Source file remains intact. PSD effects/smart objects may not render identically; native AI without PDF-compatible representation and outlined/raster text need a clean export or manual preparation in Adobe. No claim of full native format roundtrip. No font files redistributed.
6. python tools/template_import.py approve draft.kutuzov-template template-library/model-id.json --confirm-rights --confirm-proof
7. npm test && npm run build; CI verifies approved pack schema and generates catalog. Only approved packs in template-library are served. The original sources stay outside the public repo. No source upload, server conversion or fee for each customer. Existing Studio editor remains independent of this collection.

Reference: psd-tools documentation https://psd-tools.readthedocs.io/en/stable/usage.html ; Inkscape CLI https://wiki.inkscape.org/wiki/Using_the_Command_Line ; PyMuPDF page API https://pymupdf.readthedocs.io/en/latest/page.html ; Adobe AI compatibility https://helpx.adobe.com/illustrator/desktop/save-and-export/export-files-to-different-formats/save-artwork-in-illustrator-ai-format.html .

## Native output naming
Editorial packs are JSON internals, not native Illustrator files. Use .json for new editorial drafts. Historical .kutuzov-template and project JSON .kutuzov imports remain legacy-compatible. Only a genuine Illustrator AI byte stream is eligible for the public .kutuzov native name. See docs/kutuzov-native.md.
