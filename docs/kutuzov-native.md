# Native .kutuzov contract
The public design suffix is .kutuzov, containing genuine Illustrator-native AI bytes unchanged. A PDF without Illustrator private data, SVG, ZIP or JSON is not native AI. The local converter checks conservative structural markers, but does not authenticate the Adobe creator or guarantee complete native semantics. Browser copies bytes exactly, does not execute source. For AI masters with unsupported variants, use Illustrator Save As AI with PDF compatibility, then convert. Native import back into the Studio parameter model is not automatic; existing import compiler still handles supported source art.

For generated Studio designs, download the generated JSX via the export button. Run it in licensed Adobe Illustrator via File > Scripts > Other Script. It opens the two-face SVG with live text, sets trim artboards, saves real AI, reopens it to verify both artboards and editable text, then copies bytes unchanged to the user-selected .kutuzov path. It fails closed on text or dimension mismatch, does not overwrite existing files. The native AI file retains any raster artwork as raster; unsupported SVG effects and font substitutions require manual proof. For a genuine imported AI master, the byte converter preserves every layer and proprietary effect without conversion. Unknown extension recognition is not documented by Adobe; use the local converter or open-kutuzov.jsx to open an unchanged .ai copy. No new paid service. Desktop certification requires a licensed Illustrator installation. The old JSON project export is explicitly a backup, not a native design. Existing legacy JSON reads remain supported.

Native master text mode (editorial collection): use a separately retained native master, with exact text frame object names matching the pack keys (name, role, company, etc.). The downloaded JSX opens a temporary .ai copy, updates only matching unlocked visible point-text frames, shrinks overlong text to the original frame width with 6pt minimum, checks artboard/path/layer/raster/text counts and verifies text after native save/reopen. It does not support native photo, logo, QR, barcode, badge category mapping or area text; those require an explicitly prepared master or the SVG bridge. The script is not certified on desktop yet. Preserve original fonts and proof visually. Source .kutuzov native files also enter the existing local inspection compiler, which does not preserve full native semantics in the browser pack.
